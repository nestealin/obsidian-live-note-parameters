Live Note Parameters 0.1.0 is the first desktop MVP.

- Edit temporary parameters inline in Live Preview and Reading; values synchronize within a tab and reset in a fresh tab.
- Maintain Frontmatter defaults through a collapsible parameter manager, including rename previews, reference actions, draft/save/cancel and native Undo/Redo.
- Reuse native code-block copy and Copy Inline Code 2.1.0 icons. Static examples and ordinary inline copying retain their existing behavior.
- Migrate legacy HTML-comment declarations explicitly after a preview.
- Preserve readable Markdown and keep runtime values in memory.

Requires Obsidian 1.13.7+. Download main.js, manifest.json and styles.css; verify SHA256SUMS and install under plugins/live-note-parameters. See README for BRAT and detailed usage.

Accepted host: macOS / Obsidian 1.13.7. Core 21, management 21, runtime/copy 23, geometry 12 and both focus modes passed. Mobile, pop-out windows and physical IME acceptance remain outside this MVP. Community-directory submission has not been performed.
